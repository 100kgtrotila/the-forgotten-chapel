# Lucy angel

Scan source and required credit: **Stanford University Computer Graphics Laboratory — Stanford 3D Scanning Repository**.

Source and usage terms: https://graphics.stanford.edu/data/3Dscanrep/

The repository permits research use, free redistribution and mirroring with source acknowledgement. Commercial use requires permission from Stanford. This is not a CC0 or MIT-licensed model. The Three.js software license does not replace the scan's usage terms.

The 100,000-triangle PLY was obtained from the official Three.js example repository:
https://github.com/mrdoob/three.js/blob/dev/examples/models/ply/binary/Lucy100k.ply

Local conversion to glTF preserved all 50,002 vertices and 100,000 triangles, computed smooth vertex normals, centered X/Z, grounded Y and normalized height to one unit. The material is an untextured matte limestone. No original textures existed in this PLY variant.
